# Práctica D3 - Análisis de cadenas

## Descripción
Programa en Python que analiza una frase introducida por el usuario y muestra un informe con diferentes estadísticas.

## Funcionalidades
- Contar caracteres.
- Contar vocales.
- Contar consonantes.
- Contar dígitos.
- Contar espacios.
- Encontrar la letra más repetida.
- Comprobar si es un palíndromo.
- Mostrar la frase al revés utilizando un bucle.

## Funciones
El programa está organizado en funciones independientes, cada una encargada de realizar un cálculo.

## Archivos
- main.py: código principal.
- tabla_pruebas.md: tabla de pruebas.
